Requirements (R packages): ape (v5.8-1 tested), phytools (v2.5-2 tested), and caper (v1.0.4 tested)
The functions "compute_Pmixed_topological" and "compute_Pmixed_heightadjusted" each takes as input a phylo object ("tree") and a vector ("tip_AIP_type") specifying the AIP type of each tip genome. 
The order of AIP types in "tip_AIP_type" must match the order of tips in "tree".
